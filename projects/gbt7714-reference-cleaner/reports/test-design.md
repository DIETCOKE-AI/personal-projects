# 独立测试设计

## 数据性质

`examples/mixed_references.json` 包含20条输入，覆盖期刊论文J、会议析出论文C、专著M、学位论文D、在线资源EB/OL五类。r01和r02保留课程题目给出的信息，未增加无法确认的作者，使用 `authors_truncated: true` 明示原始作者列表已截断；r02只保留英文名字首字母Q/H/J，不扩写未知全名。其他条目均为教学构造；example.org与DOI样式标识仅用于测试，不能用作文献真实性依据。

缺作者或缺年份转入草稿是本工具为课程提交设置的质量门槛；该门槛不等同于声称GB/T 7714在所有场景都强制要求这些字段。特别地，2025版允许无主要责任者时省略责任者，在线资源在没有发布日期时可只著录引用日期。测试针对本工具声明的子集与质量策略，不代表对标准全部规则的合规认证。

`examples/expected_references.txt` 在运行被测程序前逐条人工编写，作为独立预期结果；禁止从实际输出反向生成该文件。默认作者大小写与题目示例保持一致。

## 人工预期

| 输入ID | 条件 | 预期处置 |
| --- | --- | --- |
| r01 | 中文期刊，已知前三作者与截断标记，页码含en dash | 输出第1条，前三作者后“等”，页码4055-4078 |
| r02 | 英文会议，作者姓名分字段，页码双连字符 | 输出第2条，与题目示例逐字一致 |
| r03、r08 | 同一本书，空格和类型名称写法不同 | 合并，保留首次出现位置，来源均可追溯 |
| r04、r07 | 同DOI，URL前缀和大小写不同 | 合并，DOI规范成10.5555/example.004 |
| r09、r10 | 同DOI，前一条缺页码 | 合并并补201-216，进入正式结果 |
| r03、r11 | 同题、同作者、同年份，但版次2版与3版不同 | 保留两条，不误删不同版本 |
| r04、r12 | 单复数造成近似题名 | 保留两条，只提示复核 |
| r04、r15 | 题名等相同，DOI不同 | 保留两条并记录冲突 |
| r13 | 作者缺失 | 草稿，列出缺失项，不编造作者 |
| r14 | 年份缺失 | 草稿，列出缺失项，不猜测出版年 |
| r17 | 完整的四位中文作者 | 输出前三作者加“等” |
| r18 | 全角数字、全角空格、em dash | 规范数字、空格和页码分隔符 |
| r05、r06、r16、r19、r20 | 学位论文、网页和中英文专著等 | 各自按类型输出 |

数量守恒：20输入 = 17去重后条目 + 3重复项；17 = 15正式结果 + 2待补草稿。不同DOI的两个相似条目会产生外观相同的正式引用；这是保守保留冲突而非去重失败，需人工复核。

## 执行与可复核性

从技能目录运行：

```text
python scripts/format_references.py --input examples/mixed_references.json --outdir reports/example-output
python -m unittest discover -s tests -v
```

黑盒验收测试使用子进程运行CLI，并将实际结果写入临时目录。测试覆盖人工黄金文本、两条课程示例、五类文献、去重数量与来源、补全、冲突保留、缺失项不造假、连续编号、Unicode规范化、相同原始输入下四个输出逐字节重跑一致性、规范化数据回读后的引用文本一致性、作者大小写选项、空输入、错误JSON和错误顶层结构。规范化回读不承诺审计原始输入计数相同，因为回读时的输入已为去重记录。实际通过数量和输出由运行日志记录，不在此预先声明。
