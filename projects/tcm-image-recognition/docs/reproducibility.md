# 源码范围与复现条件

## 公开内容

- 项目背景、实际架构、个人贡献与历史工作时间线。
- 代表性实验、23次200类评估摘要及指标口径。
- 脱敏的Flask后端、Vue/Electron前端和PyTorch算法核心源码快照。
- 各模块公开版说明、路径/环境变量示例及本轮静态校验记录。

从[源码导航](../source/README.md)进入各模块。原有源码保持本地原状，公开副本做配置脱敏、路径配置化和静态示例资产替换；未替历史代码补齐未完成的算法或业务分支。

## 不随仓库分发的资产

模型检查点、预训练文件、原始药材图像、逐图片预测与日志、数据库备份/种子数据、实际密钥、原始开发对话和交接附件，以及Java服务、工业相机SDK和硬件运行程序不包含在本目录。依赖虚拟环境、node_modules和构建产物也不提交。

因此，此源码快照不提供一条已验证能启动整套产品的命令。每个组件的配置位置与依赖见其 `README.public.md`；需先配齐相应资产。历史95.88%等结果来自周报，未在本公开版重新训练或复测。

## 完整复现需固定的内容

| 资产 | 内容 |
| --- | --- |
| 工程版本 | 兼容的算法、推理、桌面与Java/硬件程序快照 |
| 模型 | 网络条目、输出头、检查点、预训练来源、加载匹配统计与文件摘要 |
| 预处理 | 输入尺寸、缩放/裁剪、插值、归一化、类别专属处理与TTA |
| 标签和数据库 | 有序类别映射、局部子类编号、全局主键、药材标准和初始化数据 |
| 数据划分 | 图片级train/validation/general清单，采集批次/设备及去重记录 |
| 软件环境 | 实际Python/PyTorch/timm/CUDA、Node/Java及构建版本；不能以未锁定依赖推定兼容 |
| 设备和交付 | 相机SDK、电气协议、外置程序布局、数据库服务、启动日志及端到端验收 |

99类、155类与200类应分别绑定资产；后端和算法目录中同名MobileViT_large骨干也不同。当前算法训练ckpts目录未随研究副本提供，不能用公开JSON里的version/epoch直接取到模型。

## 静态校验的含义

本次发布检查源码文件可解析性、JSON结构、公开文档链接、配置脱敏、文件范围和历史评估摘要一致性；不import项目，不启动服务，不连接数据库/服务器，不训练、推理、导出模型或操作硬件。

静态解析通过不能证明依赖导入、模型张量形状、HTTP协议、设备动作或识别性能正确。已知实现边界集中记录在[源码核查](source-review.md)。各组件的缺件和历史脚本也在组件说明中单独标注。

## 查看公开评估摘要

在项目目录内可使用Python标准库读取历史CSV：

```python
import csv

with open("results/evaluation-summary.csv", encoding="utf-8", newline="") as stream:
    rows = list(csv.DictReader(stream))

print("历史评估记录数:", len(rows))
for row in rows:
    print(row["model"], row["epoch"], row["accuracy"], row["total_samples"])
```

没有原始逐图片预测和图片，不能据此重算混淆矩阵或独立验证准确率。
