# 复现条件与公开内容

## 本目录提供什么

- 项目背景、系统流程和个人工作时间线。
- 历史周报中的代表性实验与23次200类评估摘要。
- 指标口径、资料定位与版本范围说明。

本目录是项目展示档案，未附原系统的完整训练及推理源码、模型权重、原始图像、数据库或设备程序，因此不提供可直接启动整套识别系统的命令。文档中的历史结果不是本目录重新运行得到的验收结果。

## 完整复现需配套的资产

| 资产 | 需要固定的内容 |
| --- | --- |
| 工程版本 | 算法、后端、客户端的兼容快照和提交号 |
| 模型 | 网络参数、检查点、预训练来源、加载检查与权重摘要 |
| 预处理 | 输入尺寸、缩放/裁剪、归一化、类别专属处理 |
| 标签和数据库 | 模型输出顺序、主子类映射、数据库结构及初始化数据 |
| 数据 | 图片级训练/验证/测试清单、采集设备和批次、去重与拆分规则 |
| 环境和设备 | Python/PyTorch/timm/CUDA等版本、构建启动配置、相机及串口接口资料 |

99类部署版本、155类研究与200类研究应分别绑定资产，不能只按模型名称加载任意历史权重。不同文档中的客户端与后端组合也需按具体发布版本确认。

## 如何阅读评估CSV

在项目目录内可以使用Python标准库查看文件，无第三方依赖：

```python
import csv

with open("results/evaluation-summary.csv", encoding="utf-8", newline="") as stream:
    rows = list(csv.DictReader(stream))

print("历史评估记录数:", len(rows))
for row in rows:
    print(row["model"], row["epoch"], row["accuracy"], row["total_samples"])
```

这段代码仅读取公开的历史摘要，不运行模型。原始预测CSV和图片未提供，不能据本摘要重算逐样本混淆矩阵或独立验证识别精度。
