# 个人贡献与工作时间线

记录范围为2025年8月至11月。我的工作基于团队已有的两阶段识别框架，重点是算法迭代、问题排查和交付协作。来源编号见[资料索引](evidence.md)。

## 工作主线

### 交付维护与细粒度识别

对已有版本的子类识别进行现场检查，发现并修复子模型权重未配置、模型或类别映射缺失等问题。补训栀子、枣仁等子类模型，配合后端调整映射与数据库，参与硬件和后端联调，完成99大类/111小类版本的交付收尾。[W02，第2–6页；W03，第1–2页]

后续继续采集或补采困难子类测试数据，比较不同模型与预处理方案。涉及巴戟天、北沙参、柏子仁、柴胡、覆盆子、太子参、浙贝母和郁金等任务。不同任务测试集规模和采集条件各异，不将局部100%结果概括为全系统100%。[W04，第20–32页；W05]

### 模型训练与泛化评估

参与155类单模型训练与集成策略比较，开展MNv4预处理对照；后期推进200类多架构训练和general测试，检查高验证精度与低泛化成绩之间的差距。[W03，第3–22页；W07，第3–23页；W11–W13]

在155类4,737张general测试中，两组MNv4配置分别记录92.19%与96.20%；200类5,974张general中，指定MNv4检查点记录95.88%。完整条件见[实验说明](experiments.md)。

### 错误分析与工程治理

实现错误追溯工具，从评估结果定位真实类别，分别统计已知误分、已知拒绝、未知误接受，辅助阈值与困难类别分析。修补训练日志中的最佳精度记录，增加训练曲线输出，并参与训练环境恢复、现用权重归档和技术资料整理。[W01，第21–29页；W02，第7–11页；W04，第1–19页；W10]
