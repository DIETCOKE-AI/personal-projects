本页汇总历史周报记录，未在本公开版重新训练或复测模型。资料定位见[来源索引](evidence.md)。

| 配置 | 测试epoch | Accuracy | Macro F1 | 表头及结果所在页 |
| --- | ---: | ---: | ---: | --- |
| Center Crop | 80 | 92.19% | 0.9213 | 第12–16页 |
| Force Resize | 53 | 96.20% | 0.9609 | 第17–20页 |

观察到4.01个百分点的差异，但两组是独立训练配置，检查点和训练过程均有差别。它支持在该次配置比较中Force Resize表现更好，不能作为仅改变一个测试算子就必然提升4.01个百分点的因果证据。

### 实验观察

- 同一run训练到更后期，general可能下降，例如MobileViT_large从epoch6的85.50%降到epoch60的74.77%。
- 增强PAFPN的所列检查点好于常规版，但run、epoch和策略组合同时变化，不能将收益归到单个增强模块。
- 数据扩到200类经历重组而非简单追加45个输出。训练类别顺序、权重和部署映射需要共同管理。
- 后期提出离线预训练加载等排查方向，但资料未给出改造后同条件general成绩，不能称其已解决泛化问题。

## 六种结果应分开

| 指标或场景 | 含义与使用条件 |
| --- | --- |
| 训练过程验证 | 用于训练监控和选择检查点；例如W11中14,698张上的99.16% |
| 已知类general Accuracy | 指定已知类别测试集上的分类结果，不直接衡量未知拒识 |
| Macro / Weighted F1 | 分别按类别等权或按样本支持数加权的分类F1 |
| 已知类接受率KAR | 已知输入被接受的比例，需与误分和拒绝一起读 |
| 未知类拒绝率URR | 对指定未知集合的拒识能力，未知集合变化时不可直接比较 |
| 接受域内准确率或局部现场结果 | 带筛选条件或有限品类、样本数，不能外推全部输入 |

general独立于训练过程验证，但被反复用于比较模型和epoch；不能称为最终盲测，也没有图片级清单可证明完全无重复或批次交叉。置信度是模型输出及融合分数，不是经过验证的药材真伪概率。
